# Poly Haven terrain materials

These 1K JPG maps are unmodified downloads from Poly Haven and are licensed
CC0. The runtime composites the cliff sources at load time and uses Aerial
Rocks 01 only for classifier-confirmed flatter rock.

| Asset | Poly Haven page | Included maps |
| --- | --- | --- |
| Aerial Rocks 01 | https://polyhaven.com/a/aerial_rocks_01 | Diffuse, OpenGL normal |
| Aerial Rocks 02 | https://polyhaven.com/a/aerial_rocks_02 | Diffuse, OpenGL normal |
| Aerial Rocks 04 | https://polyhaven.com/a/aerial_rocks_04 | Diffuse, OpenGL normal |
| Marble Cliff 05 | https://polyhaven.com/a/marble_cliff_05 | Diffuse, OpenGL normal |
| Marble Rock 03 | https://polyhaven.com/a/marble_rock_03 | Diffuse, OpenGL normal |
